# Spawn Command

![Luacheck](https://github.com/minetest-mods/spawn_command/workflows/luacheck/badge.svg)
[![ContentDB](https://content.luanti.org/packages/lag01/spawn_command/shields/downloads/)](https://content.luanti.org/packages/lag01/spawn_command/)
[![Luanti Forums](https://img.shields.io/badge/Luanti%20Forums-Topic%20%2310668-blue.svg)](https://forum.luanti.org/viewtopic.php?t=10668)

Adds a /spawn command that teleports you to the server spawn command.

## Dependencies

- [Luanti/Minetest](https://luanti.org/) v0.4.16+
- MTG mod `default`

### Optional

- [`cursed_world`](https://github.com/AndrejIT/cursed_world)
